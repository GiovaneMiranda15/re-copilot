# Como contribuir

1. Abra uma issue descrevendo o problema ou a ideia, com um exemplo quando der.
2. Para código: `uv sync --all-extras`, faça a mudança com teste, e `uv run pytest`.
3. Para mudanças no método (referências, perfis, regras): diga o que espera melhorar e, se possível, rode uma rodada
   do protocolo em `docs/validacao/` e anexe o resultado. Ajuste feito para um caso só tende a piorar os outros.
4. Não inclua dados reais de clientes, segredos ou dados pessoais em exemplos, testes, issues ou pull requests.

Relatos de uso real são a contribuição mais valiosa: o que a skill acertou, o que deixou passar, o que inventou e o
que você aproveitou sem reescrever.
